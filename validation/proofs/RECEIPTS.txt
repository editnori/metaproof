How to read a claim
  REAL, GENERAL k   sympy, real symbols with sign assumptions, Sum over indexed
                    symbols: holds for every number of studies k.
  REAL, k = 2..8    sympy, proven separately for each k from 2 to 8 only.
  REAL              sympy, a scalar statement with no k.
  NUMERIC           a scan over a grid, not a proof.
  NAT               Bend2, over non-negative integers only (Nat). Nat.sub is
                    truncated subtraction. No division, no real numbers.
  SAMPLED           engine_conformance.py: the metaproof code against an
                    independent formula on random SYNTHETIC inputs. Evidence,
                    not proof.
  None of these covers floating-point execution of the engine.

1. Inverse-variance weights (P01)
   REAL, k = 2..8: FE w = 1/v and RE w = 1/(v + tau2) are > 0 and each
   normalized weight is in (0, 1).
   REAL, GENERAL k: sum_i w_i / sum_j w_j = 1.
   SAMPLED: E01 (engine pooled estimate and variance at the engine's tau2).

2. Pooled estimate between the smallest and largest study estimate (P02)
   REAL, GENERAL k: for FE and RE weights (any tau2 >= 0), writing
   y_i = min + d_i (or max - d_i) with d_i >= 0, pooled - min (max - pooled)
   is identically sum w_i d_i / sum w_i, which is >= 0. So
   min y <= pooled <= max y for every k >= 1.
   REAL, k = 2..8: the same bounds directly.
   NAT (pooled_not_below_min): only the identity
   sum w (m + d) = m sum w + sum w d, with integer w, m, d. It has no
   division, does not make m the minimum, has no upper bound, and
   sum w d >= 0 comes from the Nat type. Despite its name it is not the
   lower bound; the bound is the REAL, GENERAL k result above.

3. DerSimonian-Laird tau^2 (P03)
   REAL, k = 2..8: C = S1 - S2/S1 > 0 and Q >= 0 (Q's definition equals its
   computing form).
   REAL: tau2_DL = max(0, (Q - df)/C) >= 0; Q <= df gives tau2_DL = 0; Q > df
   gives (Q - df)/C.
   DL only. REML and other iterative estimators can give tau^2 > 0 with
   Q < df: SYNTHETIC y = (0, 1, 2), v = (0.5, 0.1, 10) gives Q = 1.80 < df = 2,
   REML tau^2 = 0.149 (engine, 2026-11-02).
   NAT (trunc_zero_when_q_le_df, trunc_exact_above_df): truncated
   subtraction on integers is 0 when Q <= df and Q - df otherwise. An integer
   model of max(0, Q - df); no division by C.
   SAMPLED: E02.

4. I^2 (P04)
   REAL: the Q-based I^2 = max(0, (Q - df)/Q), for Q > 0 and df > 0, is in
   [0, 1) (each Piecewise branch decided < 1 by sympy), equals
   (H^2 - 1)/H^2, is 0 when Q <= df, and at the DL tau2 equals
   tau2/(tau2 + s^2) with s^2 = df/C (Higgins and Thompson 2002).
   REAL, k = 2..8: the typical within-study variance (k-1) S1/(S1^2 - S2)
   equals df/C.
   The engine reports I^2 = tau2/(tau2 + s^2) on random-effects rows. That is
   the Q-based form only at the DL tau2. Under REML it can be > 0 when
   Q < df (the example in 3 gives I^2 = 20.7%), so "Q <= df gives I^2 = 0"
   holds for FE and DL rows only.
   NAT (i2_slack, i2_strict_slack, i2_below_one): max(0, Q - df) + min(Q, df)
   = Q, and for integer Q >= 1, df >= 1 the numerator is at most Q - 1. No
   division by Q. Over the reals the "at most Q - 1" bound also needs
   df >= 1 (Q = 1.5, df = 0.2 gives 1.3 > 0.5); I^2 < 1 itself is the REAL
   result above.
   SAMPLED: E02 checks both I^2 forms against the engine.

5. Random-effects weights equalize as tau^2 grows (P05)
   REAL: for two studies, the weight ratio falls toward 1 (derivative < 0,
   limit 1); the more precise study's normalized weight falls (k = 2); every
   normalized weight tends to 1/k (k = 3).

6. Prediction interval contains the confidence interval (P06)
   REAL: when the PI and the CI use the same SE and c_PI >= c_CI,
   mu +/- c_PI sqrt(tau2 + SE^2) contains mu +/- c_CI SE.
   NUMERIC: t_0.975(df) > z_0.975 for df = 1..5000, 1e5, 1e7; t decreasing
   in df for df = 1..2000; the engine's pairs (riley t_(k-2), revman t_(k-1)
   against the CI's t_(k-1) or z; metafor uses the CI's own value) satisfy
   c_PI >= c_CI for k = 3..2000.
   The engine's PI uses the SE of its CI, Hartung-Knapp-scaled under HKSJ,
   so the engine PI contains its CI. A Hartung-Knapp CI does not break this.
   SAMPLED: E06 (formula for riley, revman and metafor; DL and REML; HKSJ
   off and every hksj_rule; containment in every fit; NaN for FE and for
   riley at k = 2).

7. Hedges J (P07)
   REAL: the approximate J = 1 - 3/(4 df - 1) is in (0, 1) for df > 1,
   increasing, limit 1; J(1) = 0.
   NUMERIC: the exact gamma form, which the engine uses, is in (0, 1) and
   increasing for df = 2..1000, within 0.01 of the approximation.
   SAMPLED: E03.

8. Change-from-baseline SD (P08), Handbook 6.5.2.8
   REAL: for r in [-1, 1] the radicand is >= (SDb - SDf)^2 >= 0 and the SD is
   <= SDb + SDf; it falls as r rises; r = 1 with SDb = SDf gives 0.
   SAMPLED: E04.

9. Cross-over paired SE (P09), Handbook 23.2.7, Elbourne 2002
   REAL: with r > 0 the paired SE is smaller than the parallel SE; equal at
   r = 0; larger for r < 0.
   SAMPLED: E05.

10. Splitting a shared control (P10), Handbook 23.3.4
   REAL, GENERAL k: sum over k comparisons of n/k is n, events/k sums to the
   events, and each sub-arm keeps the risk. This is the engine's split
   (shared control n divided by the number of comparisons).
   NAT (split2_keeps_n, split2_balanced, deal_keeps_n,
   deal_from_empty_keeps_n, deal2_floor_ceil, deal2_from_empty): an integer
   floor/ceil split for two arms and a round-robin integer deal for any
   number of arms keep the total; the two-arm deal is (floor(n/2),
   ceil(n/2)), so its sub-arms differ by at most one. No balance law is
   proven for three or more sub-arms. The engine does NOT run an integer
   split, so these laws describe a function the kit does not use.
   SAMPLED: E07. On the arm-level paths the engine accepts (split, combine,
   several control rows, explicit combine_arms) the control enters once in
   total, each comparison's yi and vi equal an independent formula (MD,
   Hedges g with exact J and LS variance, log ratio of means) at the split
   control n, and each row's dose is its own experimental arm's. A
   multi-period crossover must be excluded or count the placebo period
   once; several reported between-group MDs against one control must be
   refused.
   No count shows that split comparisons stay correlated (Handbook 23.3.4).

Mutants
   sympy M01-M15: each wrong formula cannot be proven and has a SYNTHETIC
   counterexample.
   Bend A-E: each is refuted by a checked law refute_mutant_<X> in
   meta_laws.bend whose hypothesis is the mutant file's own law, quantified
   the same way (run_bend.py compares the text and the mutant's function
   bodies). That law derives Empty, so the mutant law is false over Nat. Bend
   also rejects the mutant's copied proof with a type error at that law; the
   rejection is illustrative only, because Bend rejects a wrong proof of a
   true statement too. An ssh, wrapper, parse, import or unknown-name failure
   is an ERROR, never a rejection.
     A  floor(n/2) to each of two arms: false at n = 3.
     B  shared control counted in both comparisons (n + n = n): false at n = 1.
     C  numerator max(0, df - Q): false at Q = 5, df = 2.
     D  I^2 slack without min(Q, df): false at Q = 1, df = 2.
     E  k-way deal that drops the person on rotation: false at n = 1 over two
        sub-arms (deals [0, 0]). Replaces the earlier "drops on wrap" mutant,
        which lost people only with a single arm (no split) and so tested
        nothing about a real split.

Not covered by any proof here
   Floating-point behaviour of the engine; REML, PM and ML estimation;
   Q-profile limits; meta-regression; median and range conversions; the
   correlation between split comparisons.
